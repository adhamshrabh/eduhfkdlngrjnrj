# «أَلِف يسافر» — قصّة برهانٍ للأنواع الثمانية

**الغرض:** إثبات أن أنواع النشاط الثمانية تعمل، **كلٌّ في أقوى صورةٍ يقدر
عليها**، داخل سياقٍ سرديّ واحد متماسك.
**ليست خطّة درس.** طولها (أحد عشر مشهداً) تغطيةٌ مقصودة لا عيب.
**ما ينقص:** سبع صور تُولَّد (§4) وبطاقاتٌ تُربَط (§5). لا كود جديد.

---

## ١. لماذا قصّةٌ جديدة، ولماذا هذه

`yara_finds` المبذورة تغطّي **ستّة** أنواع، وتترك `pick-correct` و`drag-match`
بلا عرض، وتعرض `jigsaw` بلا مسار بطاقة، و`pick-correct` بلا إطارٍ متنقّل
(v1.0.24). هذه القصّة تُكمل الثمانية.

والمعيار الذي صُمِّمت عليه ليس «كم نوعاً ظهر» بل: **هل ظهر كلّ نوعٍ وهو يفعل
أصعب ما يستطيع؟** نوعٌ يظهر في أتفه إعداداته لا يُثبت شيئاً — أحجيةٌ من قطعتين
على بلاطةٍ ملوّنة تمرّ بلا أن تختبر شيئاً في `JigsawRunner`.

### ١.١ السياق: سلسلة سببية لا زينة

كل نشاطٍ هنا **تسبّبه** الحبكة، ولا يُركَّب عليها:

```
يحزم → صورته تمزّقت فيرمّمها → فقد جوازه فيبحث عنه → يختار أوّل غرض
  → يملأ الحقيبة بالقاعدة → الحقيبة ثقلت فيصوّت الصفّ على ما يُترك
  → في المطار: عربتان بقاعدةٍ أخرى → بطاقة الصعود ناقصة حرف
  → نداء المسافرين يرتّب اسمه → هدايا الوداع → الإقلاع
```

اختبار السياق: **احذف أيّ نشاطٍ فتنكسر السلسلة**. إن أمكن حذفه بلا أثر، فهو
زينة — وهذا ما يفرّق قصّة برهانٍ عن عرضٍ لقائمة ميزات.

شيء اليوم.

## ٣. الإعداد الدقيق للمشاهد الحاسمة

ما دونها مباشر؛ هذه الخمسة هي التي يقع فيها الخطأ.

### مشهد ١ — الاستكشاف (وهو ما يجعل المشهد الأوّل حيّاً)

```jsonc
"elements": [
  { "id": "alif",  "alias": "arnab",  "type": "character", "idle": "blink" },
  { "id": "bag",   "alias": "haqiba", "type": "object" },
  { "id": "it_1",  "alias": "asad",   "type": "object", "onTap": { "audio": "n_asad" } },
  { "id": "it_2",  "alias": "ananas", "type": "object", "onTap": { "audio": "n_ananas" } },
  { "id": "it_3",  "alias": "apple",  "type": "object", "onTap": { "audio": "n_apple" } }
]
```

⚠️ `onTap` **لا يعمل أثناء نشاط** (حارسه `!puzzle.isActive`). فهو حكرٌ على
المشاهد الحوارية — ولهذا يبقى المشهد الأوّل بلا نشاط عمداً، ولا يُدمَج مع
الثاني.

### مشهد ٢ — الأحجية، والمزلق الذي يُفسدها

```jsonc
{ "type": "jigsaw",
  "question": { "text": "صورة أَلِف تمزّقت — ركّبوها!" },
  "image": "arnab_photo",
  "grid": { "cols": 2, "rows": 2 },
  "pieces": [ { "cell": 1, "alias": "photo_1" }, { "cell": 2, "alias": "photo_2" },
              { "cell": 3, "alias": "photo_3" }, { "cell": 4, "alias": "photo_4" } ],
  "wrongResponse": { "text": "ليست هذه خانتها" },
  "onSolved": { "showObject": "arnab_photo", "nextScene": "s3" } }
```

⚠️ **`arnab_photo` يجب أن تملأ إطارها حتى الحواف — لا شخصيةٌ على شفافية.**
القطع تُقصّ هندسياً من مستطيل الصورة، فصورةٌ شفّافة الأطراف تعطي أرباعاً شبه
فارغة. والقطعة الفارغة **تبقى قابلة للسحب** (Pixi يختبر المستطيل لا البكسل)
**لكنها غير مرئية** — فيرى الصفّ أحجيةً لا تكتمل، بلا رسالة خطأ. ولهذا
المطلوب **صورةٌ في إطار**: أَلِف داخل بطاقةٍ مستطيلة ملوّنة الخلفية.

و`pieces[]` هنا ليست زينة: بها يُثبَت مسار البطاقة (§5).

### مشهد ٣ — البحث بعناصر المشهد نفسه

```jsonc
{ "type": "find",
  "question": { "text": "أين جواز سفر أَلِف؟" },
  "spots": [
    { "id": "sp1", "alias": "bed",      "label": "السرير",  "relation": "under",  "correct": true },
    { "id": "sp2", "alias": "haqiba",   "label": "الحقيبة", "relation": "inside" },
    { "id": "sp3", "alias": "gift_box", "label": "الصندوق", "relation": "behind" }
  ],
  "onSolved": { "showObject": "jawaz", "nextScene": "s4" } }
```

المواضع الثلاثة **عناصر موجودة في المشهد**، واثنان منها أصولٌ معادة من قصصٍ
أخرى. والشاشة تقول عند كل محاولة: «ليس داخل الحقيبة» / «نعم! تحت السرير».

### مشهد ٤ — الإطار المتنقّل (أهمّ قدرةٍ غير معروضة)

```jsonc
{ "type": "pick-correct",
  "question": { "text": "أيّ غرضٍ يبدأ باسم أَلِف؟" },
  "navigate": true,
  "choices": [
    { "id": "c1", "alias": "apple" },     { "id": "c2", "alias": "asad", "correct": true },
    { "id": "c3", "alias": "butterfly" }, { "id": "c4", "alias": "bird" },
    { "id": "c5", "alias": "ananas" },    { "id": "c6", "alias": "iwazza" }
  ] }
```

⚠️ **إجابةٌ صحيحة واحدة فقط.** المُصيِّر يُبلّغ الحلّ عند **أوّل** خيارٍ
`correct` — فأربع إجاباتٍ صحيحة تجعل النشاط يُحلّ بنقرةٍ واحدة. والأربعة
كلّها تُغطّى في مشهد ٥ (`sort`)، وهو المبني للمجموعات.

و`navigate: true` يحوّل الجواب من «زرّ لكل خيار» إلى **إطارٍ يتنقّل بزرَّين** —
فستّة خيارات تُجاب من صندوقٍ بخمسة أزرار. وهو ما يجعل النشاط قابلاً للّعب من
آخر الغرفة.

### مشهد ٦ — التصويت، لا الامتحان

```jsonc
{ "type": "all-respond",
  "question": { "text": "الحقيبة ثقيلة! أيّ غرضٍ نترك؟" },
  "options": [
    { "id": "op_1", "alias": "asad", "label": "الأسد" },
    { "id": "op_2", "alias": "ananas", "label": "الأناناس" },
    { "id": "op_3", "alias": "iwazza", "label": "الإوزّة" }
  ],
  "poll": true,
  "expect": 12, "waitSeconds": 30 }
```

⚠️ **هذا هو الاستعمال الصحيح للنوع، وهو أقوى من «ارفعوا بطاقة ما يبدأ بـ أ».**
`all-respond` مبنيٌّ بلا رابحٍ ولا خاسر: كل بطاقة تُعدّ وتظهر في التوزيع، ولا
ردّ خطأ. وسؤالٌ له جوابٌ واحد يتحايل على هذا التصميم؛ أمّا **سؤالٌ لا جواب
واحد له** فيستعمله كما هو — `poll: true` (v1.0.32): تُعرض الصور الثلاث،
وتملأ كل بطاقةٍ نجمةً في عدّاد الصفّ، ثم تظهر النجوم تحت صورها معاً ويكبر
ما اختاره أكثرهم. والمعلّمة تقرأ رأي الغرفة لا تصحّحه.

و`expect` **عدد الحاضرين اليوم** — الحقل الوحيد الذي يتغيّر قبل كل تشغيل.

## ٤. الأصول — سبعٌ تُولَّد، وستٌّ تُعاد

### ٤.١ تُولَّد

نسقٌ واحد: **تصييرٌ ثلاثيّ الأبعاد ناعم، ألوان فاتحة، PNG بخلفية شفّافة** —
مطابقةً لأصول `yara_story`، وإلّا بدت القصّة مركّبةً من مصدرين.

| الاسم | ما هو | المقاس | شرط |
|---|---|---|---|
| `arnab` | أرنب أَلِف، واقفاً | ٦٠٠×٦٠٠ | شفّافة، كاملٌ داخل الإطار |
| `arnab_photo` | **صورة أَلِف داخل إطارٍ مستطيل ملوّن** | ٨٠٠×٨٠٠ | ⚠️ **تملأ الإطار حتى الحواف، بلا شفافية حوله** — شرط الأحجية |
| `haqiba` | حقيبة سفر **مفتوحة** | ٨٠٠×٦٠٠ | تُرسم سلّةً، فلتُفهَم أن شيئاً يدخلها |
| `jawaz` | جواز سفر صغير | ٤٠٠×٤٠٠ | شفّافة |
| `asad` | أسد | ٦٠٠×٦٠٠ | وجهٌ ودود لا مفترس |
| `iwazza` | أوزة | ٦٠٠×٦٠٠ | شفّافة |
| `ananas` | أناناس | ٦٠٠×٦٠٠ | شفّافة |

اختياري: `bg_airport` خلفية مطار للمشهد ٧ (تزيد منطقية «العربتين»؛ وبدونها
يُستعمل ظهر الغرفة).

⚠️ **قاعدةٌ على كل صورة: اسمٌ واحد بديهيّ.** صورةٌ تُسمّى «عصفور» أو «طائر»
تُفسد الفرز والبطاقة معاً. اختبار: أرِها لثلاثة — إن اختلفوا، أعِد رسمها.

### ٤.٣ أصوات

تُسجَّل في الاستوديو (يقبل `webm` من المتصفّح كما يقبل `mp3`/`wav`):

- **٣ مقاطع أسماء** للمشهد الأوّل: `n_asad` · `n_ananas` · `n_apple` — كلمةٌ
  واحدة لكلٍّ. بدونها يكون المشهد الأوّل صورةً ساكنة، ولا يُثبَت `onTap`.
- **٧ مقاطع أسئلة**: واحدٌ لكل مشهد نشاط.
- `v_yay` تشجيع — أو أعِد `yara_story/audio/success.mp3`.

## ٥. البطاقات — وما يُثبته ربطها

| البطاقة | يُثبت |
|---|---|
| `photo_1` … `photo_4` | **مسار البطاقة في `jigsaw`** — القطعة تهبط في خانتها هي، أيّاً كان الترتيب (v1.0.25 §6) |
| `أ` · `ر` · `ن` · `ب` | مسار `sequence` |
| `asad` · `ananas` · `iwazza` | `all-respond` و`card-answer` معاً |
| `apple` · `butterfly` | البطاقة الخاطئة في `card-answer` تستحقّ ردّاً (v1.0.20) |

⚠️ **مزلقان:**

1. **اسم البطاقة = الاسم المستعار حرفاً بحرف.** مسافةٌ زائدة تُبطل المطابقة.
2. **`أ` ليست `ا`** — U+0623 مقابل U+0627. وكلمة «أَرنب» تبدأ بالأوّل؛ تحقّقتُ
   منها برمجياً، وتنقسم في مقسّم الكلمات بالاستوديو إلى `أ ر ن ب` بالضبط.

والحدّ الأدنى إن ضاق الوقت: **بطاقتا أحجية + بطاقتا `card-answer`** تكفيان
لإثبات المسارين؛ والبقيّة تحسين.

## ٦. ما يبقى غير مُثبَت — يُقال ولا يُخفى

| القدرة | لماذا لا تظهر هنا |
|---|---|
| `sequence` بخطوةٍ **مكرّرة** (v1.0.22 §2.2) | لا كلمة ألفٍ مألوفة للأطفال فيها حرفٌ مكرّر. الحالة مغطّاة بالكود لا بقصّة — وتستحقّ مشهداً في قصّةٍ أخرى («سرير» مثلاً) |
| `find` بموضعٍ لا عنصر له | حالة سقوطٍ آمن، لا تُؤلَّف عمداً في قصّةٍ تُعرَض |
| تفريعُ الحوار (`choices`) و`idle: "sway"` وتوقيت الحركة بالصوت | خارج نطاق أنواع النشاط — قدراتٌ أخرى تستحقّ قصّة برهانٍ خاصّة بها |

وما لا تستطيعه المنصّة أصلاً: لا خطّ يد، ولا تعرّف على كلام، ولا تقرير لكل
طفل (قرارٌ معماريّ: صفر بيانات شخصية)، ولا تفريعٌ بحسب نتيجة الصفّ.

## ٧. خطوات التنفيذ

1. **توليد الصور السبع** بمواصفات §4.1 — و`arnab_photo` أدقّها وأخطرها.
2. **تسجيل ١١ مقطعاً** (٣ أسماء + ٧ أسئلة + تشجيع).
3. **ربط البطاقات** بحسب §5، بالأسماء حرفاً بحرف.
4. **كتابة أمر بذر** `seed_alif_travels` على نسق `seed_yara_finds`: يفحص
   المصادر قبل أي كتابة، ويطبع أنواع النشاط الواردة في القصّة.
5. **الفحص الآليّ:** `npm run verify` يجب أن يبقى أخضر — القصّة محتوى لا كود.
6. **فحص الاستوديو:** افتح المشاهد الأحد عشر؛ كلٌّ يعرض محرّر نشاطه، وشريط
   التحقّق يقول «المحتوى صالح»، ولا تحذير «لا بطاقة» باقياً.
7. **التشغيل الحيّ على بروجكتور** — البند الذي لا يكشفه اختبار: هل يُقرأ
   الإطار المتنقّل وقطع الأحجية وأسماء السلال من آخر الغرفة؟

## ٨. ملحق: السند التعليمي

القصّة مصمَّمة للبرهان لا للتدريس، لكنّ محتواها ليس اعتباطياً: ترتيب المهامّ
يتبع تدرّج **تعرُّف ← تمييز ← تصنيف ← إنتاج**، و`card-answer` آخرها لأنه
الوحيد بفضاء إجابةٍ مفتوح.

وأُسندت أنواع النشاط نفسها في
[`Activity-Evidence-Base.md`](./Activity-Evidence-Base.md). أمّا اختيار الألف
فحجّته خاصّة بالعربية: **لا تتّصل بما بعدها، فلها صورتان اثنتان** بينما لحروفٍ
أخرى أربع — وتفاوت عدد الصور (allographs) أحد أوضح مصادر الصعوبة عند
المبتدئين ([Asadi et al. 2021](https://link.springer.com/article/10.1007/s11145-020-10086-6)،
[Frontiers 2025](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2025.1628051/full)).

وما دون ذلك — الحبكة، وطول القصّة، وترتيب المشاهد — **اجتهاد تصميم**، ولا
يُسنَد إلى ورقة.
