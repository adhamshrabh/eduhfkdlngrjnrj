# Scene Model Specification — Patch v1.0.26

**`sort` — الطفلة تضع كل شيء حيث ينتمي، والقاعدة قد تتغيّر في المشهد التالي.**

`schemaVersion` يبقى `"1.0"`. نوع نشاط جديد. حقلان مطلوبان — `bins`
و`items` — ولا يتغيّر معنى أي حقل قائم.

يبني على [v1.0.25 §5](./Scene-Model-Specification-v1.0.25.md) (متى يُحكَم)
و[v1.0.8](./Scene-Model-Specification-v1.0.8.md) (الاختيار قصد) بلا تعديل
فيهما.

---

## ١. الفجوة

بعد [v1.0.25](./Scene-Model-Specification-v1.0.25.md) صار النموذج يسأل ثلاثة
أسئلة: **أيّها؟** و**بأي ترتيب؟** و**أين يعود هذا؟**

وثلاثتها عن **شيءٍ واحد** في كل مرّة. ولا شيء فيها يسأل: **ما الذي يجمع
هذه الأشياء؟** — أن تنظر الطفلة إلى ستّة أغراض فترى فيها صنفَين.

التصنيف ليس تفصيلاً: هو العملية التي تجعل «الأشياء» قابلةً للعدّ والوصف
والمقارنة، وهو أوّل ما تفعله الرياضيات قبل أي رقم.

وله وجهٌ ثانٍ أهمّ: **أن تتغيّر القاعدة**. أن تفرز الطفلة بالمالك، ثم
يُقال لها «الآن بالحجم» فتترك القاعدة الأولى وتأخذ الثانية — وهي بعينها
العملية التي تقيسها مهمّة DCCS، وأحد ثلاثة مكوّنات للوظائف التنفيذية. انظر
[`Activity-Evidence-Base.md`](./Activity-Evidence-Base.md) لما يقوله الدليل
وما لا يقوله.

## ٢. النموذج

```jsonc
{
  "type": "sort",
  "question": { "text": "أي هذه أغراض يارا؟", "audio": "ask_sort" },
  "bins": [
    { "id": "b1", "label": "أغراض يارا", "image": "box_pink", "x": 480, "y": 820 },
    { "id": "b2", "label": "ليست لها" }
  ],
  "items": [
    { "alias": "doll", "bin": "b1" },
    { "alias": "apple", "bin": "b2", "x": 700, "y": 300 }
  ],
  "wrongResponse": { "text": "انظري مرّةً أخرى — بعضها ليس في مكانه" },
  "effects": { "onCorrect": { … }, "onWrong": { … } },
  "onSolved": { "nextScene": "s5" }
}
```

| الحقل | مطلوب | يقول |
|---|---|---|
| `bins` | ✔ | السلال. لكلٍّ `id` و`label`؛ و`image` و`x`/`y` اختيارية |
| `items` | ✔ | الأغراض. لكلٍّ `alias` (صورة من `assets[]`) و`bin` (سلّتها الصحيحة) |
| `question` · `wrongResponse` · `effects` · `onSolved` | — | كما في كل نوع |

سلّتان على الأقلّ، وغرضٌ واحد على الأقلّ — وسلّةٌ واحدة ليست فرزاً.

## ٣. الحكم عند النهاية — الجهة الثانية من قاعدة v1.0.25

لا يُقال شيء عن غرضٍ وُضع. **يُحكَم على الفرز كلّه حين يُوضع آخر غرض.**

وهذا تطبيقٌ مباشر للقاعدة التي ثبّتتها [v1.0.25 §5](./Scene-Model-Specification-v1.0.25.md):

> يُحكَم فوراً حين تكون التغذية الراجعة كامنةً في الفعل المادّي نفسه.
> ويُحكَم عند النهاية حين يكون الحكم قاعدةً يملكها الكبير.

قطعة الأحجية تدخل أو لا تدخل — المادّة تخبر. أمّا التفّاحة في سلّة «أغراض
يارا» فتقع فيها تماماً كما تقع في الأخرى: **لا شيء في السلّة يعرف**. الصنف
قاعدةٌ في رأس الكبير، لا خاصّية في الشيء.

والحكم بعد كل غرض كان سيحوّل سؤالاً واحداً عن **قاعدة** إلى ستّة أسئلة عن
أغراض مفردة — فتُحلّ المهمّة بالتجريب لا بالتصنيف، وتخرج الطفلة وقد ملأت
السلال ولم تسمِّ القاعدة قطّ.

### ٣.١ ولا شيء يُقلَب حين يكون الفرز خاطئاً

الأغراض **تبقى حيث وضعتها الطفلة**. يُقال ردّ الشخصية، ثم أيّ تحريكٍ بعده
يُعيد الحكم على الفرز كلّه.

وهذا مقصود في الاتجاهين:

- **لا تُفرَّغ السلال.** إفراغُ ستّة أغراض عقابٌ على خطأٍ في واحد، ويمحو
  خمسة قراراتٍ صحيحة اتّخذتها الطفلة.
- **ولا يُقال أيّها الخطأ.** تعليم الخطأ بعينه هو جوابُ الكبير، لا نظرةُ
  الطفلة. و«انظري مرّةً أخرى» تُبقي القاعدة موضع السؤال.

وإعادة الحكم عند أيّ تحريك ليست حكماً على الغرض المحرَّك: هي إعادةُ تقديمٍ
للفرز كلّه، تختارها الطفلة بيدها حين ترى أنها انتهت ثانيةً.

## ٤. تبديل القاعدة — بلا حقلٍ جديد

ما يحتاجه تمرين المرونة المعرفية — «فرزتِ بالمالك، والآن افرزي بالحجم» —
**يُؤلَّف اليوم بلا أي إضافة إلى العقد**: مشهدان متتاليان، بالأغراض نفسها
وبتوزيعٍ مختلف على سلالٍ مختلفة.

```jsonc
// المشهد ٤ — بالمالك
{ "type": "sort",
  "bins": [{ "id": "hers", "label": "أغراض يارا" }, { "id": "not", "label": "ليست لها" }],
  "items": [{ "alias": "doll", "bin": "hers" }, { "alias": "apple", "bin": "not" }] }

// المشهد ٥ — الأغراض نفسها، والقاعدة الأخرى
{ "type": "sort",
  "bins": [{ "id": "big", "label": "كبير" }, { "id": "small", "label": "صغير" }],
  "items": [{ "alias": "doll", "bin": "big" }, { "alias": "apple", "bin": "small" }] }
```

ولم يُضَف حقل `switchRule` عمداً. الحقل كان سيصف داخل نشاطٍ واحد ما يصفه
مشهدان بوضوحٍ أكبر، ويضيف إلى العقد سطحاً ثانياً للشيء نفسه. والقاعدة
الثابتة هي التي تمنعه: **لا يُضاف حقلٌ لما يُعبَّر عنه أصلاً.**

وللأثر التعليمي شرطٌ يُقال هنا لا في الكود: **الأغراض نفسها في المشهدين**.
أغراضٌ جديدة تجعله فرزاً ثانياً لا تبديل قاعدة — والفارق هو التمرين كلّه.

## ٥. أين تقع السلال والأغراض

كلاهما بمواضع اختيارية في فضاء التصميم (١٩٢٠×١٠٨٠):

- **سلّةٌ بلا `x`/`y`** تُنشر في صفٍّ أسفل المسرح، متوسّطةً بالمسافات نفسها.
- **غرضٌ بلا `x`/`y`** يُنشر في صفٍّ أعلى، فوق السلال.

والانتماء يُقاس بالمركز: الغرض في سلّةٍ إن وقع مركزه داخل مستطيلها. وغرضٌ
أُفلت خارج كل سلّة **ليس خطأً** — هو غرضٌ لم يوضع بعد، فيعود إلى صفّه
ولا يُحتسب.

`image` على السلّة اختيارية. وبغيابها تُرسم السلّة إطاراً يحمل `label` —
فلا يتعطّل نشاطٌ لأنّ أحداً لم يرسم صندوقاً.

## ٦. البطاقة والزرّ

القصد الوارد يُحلّ إلى **غرض** بعنوانه (المعرّف المولَّد، ثم `alias`، ثم
الموضع). والغرض الذي يسمّيه قصدٌ ينتقل إلى **سلّته الصحيحة**.

وهذا يجعل النشاط قابلاً للّعب ببطاقةٍ من آخر الغرفة، لكنّه **يزيل التصنيف
من المهمّة**: البطاقة تضع الغرض في مكانه الصحيح بلا أن تقرّر الطفلة. فهو
طريقٌ للوصول — لطفلٍ لا يصل إلى الشاشة — لا الطريقة المقصودة، ويُقال ذلك
في الاستوديو بوضوح.

⚠️ **ولهذا لا يُحكَم على الفرز إلّا حين يكون كل غرضٍ موضوعاً**: نشاطٌ كُمِّل
كلّه بالبطاقات يُحلّ دائماً، وهو أثرٌ مقصود — البطاقة لا تُخطئ لأنها تسمّي
غرضاً لا سلّة.

## ٧. ما لا تضيفه هذه الرقعة عمداً

**`switchRule`** — §٤ أعلاه.

**سلّةٌ بسعةٍ محدودة** («ثلاثة فقط في كل سلّة»). قيدٌ مختلف عن التصنيف،
ويقيس العدّ لا الصنف. ولا يوجد اليوم ما يطلبه.

**غرضٌ ينتمي إلى سلّتين.** `bin` مفردة. الغرض الذي يصحّ في سلّتين يجعل
«خطأ» غير قابلة للتعريف، وهو سؤالٌ لم تُكمِل المؤلّفة تحديده.

## ٨. ما يفحصه المُتحقِّق

| الحالة | الدرجة |
|---|---|
| `bins` ليست مصفوفةً بسلّتين فأكثر | خطأ — سلّةٌ واحدة ليست فرزاً |
| `bins[].id` غائب أو مكرّر | خطأ — القصد يصير ملتبساً |
| `bins[].label` غائب | تحذير — سلّةٌ بلا اسم لا تقول للطفلة ما تجمعه |
| `items` ليست مصفوفةً بغرضٍ فأكثر | خطأ |
| `items[].alias` غائب | خطأ — بلا صورة لا يُرى الغرض |
| `items[].bin` لا يطابق أي `bins[].id` | خطأ — غرضٌ بلا سلّة صحيحة لا يُحلّ أبداً |
| سلّةٌ لا ينتمي إليها أي غرض | تحذير — سلّةٌ تبقى فارغة في كل حلٍّ صحيح |
| `x`/`y`/`scale` ليس عدداً، أو `scale ≤ 0` | خطأ |
| `question` غائب | تحذير — فرزٌ بلا سؤال لا يقول بأي قاعدة |

**المُتحقِّق يشخّص ولا يمنع.**

---

## ٩. السقوط الآمن في زمن التشغيل

| العطل | ما يفعله المحرّك |
|---|---|
| صورة غرضٍ غير محمّلة | يُتخطّى الغرض، ويُلعب الفرز بما بقي |
| لم يبقَ غرضٌ قابل للرسم | يُبلَّغ النشاط محلولاً وتمضي القصّة |
| `bin` لغرضٍ لا يطابق سلّة | يُتخطّى الغرض (وإلّا تعذّر الحلّ أبداً) |
| سلّةٌ بلا `image` أو بصورةٍ مفقودة | تُرسم إطاراً باسمها |

القاعدة الثابتة: خطأ تأليفٍ لا يجوز أن يصير طريقاً مسدوداً أمام صفٍّ.
