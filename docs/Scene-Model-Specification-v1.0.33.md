# Scene Model Specification — Patch v1.0.33

**الكلمة على الصورة، والحرف داخل الكلمة، والمسار عبر نقاط.**

`schemaVersion` يبقى `"1.0"`. كل حقلٍ هنا اختياري، ونوع مؤثّرٍ واحد جديد
(`highlight-letter`)، وقيدٌ يُرفَع في `pick-correct` (الجواب الصحيح
الواحد). ولا نوع نشاطٍ جديد.

السند التعليمي: [Activity-Evidence-Base.md](./Activity-Evidence-Base.md) —
«الحرف في موضعه».

---

## ١. الفجوة

درسُ حرفٍ في الروضة يسير هكذا: بالونٌ ينزل يحمل «بالون»، تُضاء الباء فيه،
تخرج من الكلمة بشكلها «بـ»، ثم يختار الطفل من بالوناتٍ كل كلمةٍ تبدأ بها.

وقبل هذه الرقعة لم يكن في النموذج شيءٌ من ذلك إلّا بالرسم:

| ما يحتاجه الدرس | ما كان متاحاً |
|---|---|
| كلمة مكتوبة على البالون | صورة مرسومة للبالون **مع** الكلمة، لكل كلمة |
| إضاءة حرفٍ فيها | صورةٌ ثانية مرسومة بالحرف ملوّناً، و`set-image` |
| إخراج «بـ» بشكلها | صورةٌ ثالثة |
| نزولٌ بمنحنى | `move` بخطٍّ مستقيم، أو سلسلة `move`ات بزوايا |
| «اختر **كل** ما يبدأ بالباء» | جوابٌ صحيح واحد |

فدرسُ حرفٍ واحد كان يحتاج نحو عشر صور، ودرس الحرف التالي عشراً أخرى.
هذه الرقعة تجعل الكلمة والحرف **بيانات**، فيُعاد الدرس لحرفٍ آخر بكتابة
كلماتٍ أخرى لا برسم صورٍ أخرى.

## ٢. المسار عبر نقاط — `move.path`

```jsonc
{ "type": "move", "target": "balloon_1",
  "path": [{ "x": 1500, "y": 120 }, { "x": 700, "y": 380 }],
  "to":   { "x": 960, "y": 620 },
  "duration": 3, "ease": "ease-in-out" }
```

- `path` نقاطٌ **يمرّ بها** العنصر بالترتيب في طريقه إلى `to`.
- المنحنى **يمرّ بكل نقطة**. هو Catmull-Rom المركزيّ، لا Bézier الذي
  يقترب من نقاطه ولا يمرّ بها، لأن المؤلّفة تنقر نقطةً وتتوقّع أن يمرّ البالون
  بها.
- السرعة موزّعة على **المسافة** لا على المقاطع. `ease` المؤلَّف هو وحده ما
  يغيّرها.
- يبدأ المنحنى من حيث **يقف العنصر** لحظة بدء الحركة (بعد `from` إن
  وُجد)، كما يبدأ `move` بلا مسار.
- `matchAudio` يعمل كما هو: المسار مدّةٌ واحدة تُمدّ مع الصوت.

**في الاستوديو**: «ارسم مسارًا بنقاط» تحت الوجهة. تنقر المؤلّفة النقاط
بالترتيب، و**آخر نقرة هي الوجهة**. فإيماءةٌ واحدة تضبط الاثنين، ونقرةٌ
واحدة تعني «تحرّك إلى هنا». الإنهاء يكون بـEnter أو بنقرةٍ مزدوجة،
وBackspace يحذف آخر نقطة، وEsc يُلغي. والمنحنى المرسوم على المسرح هو
المنحنى نفسه (`pathSampler`) الذي يطير عليه المحرّك.

## ٣. كلمةٌ على الصورة — `elements[].word`

```jsonc
{ "id": "balloon_1", "alias": "balloon", "word": { "text": "بالون", "y": 0.4 } }
```

- `text` الكلمة. تُكتب **فوق الصورة وابنةً لها**، فتتحرّك وتكبر وتتمايل
  معها، وتبقى إن بدّل `set-image` الصورة تحتها.
- `y` موضع وسطها من أعلى الصورة، كنسبةٍ من ارتفاعها (افتراضيّاً ٠٫٤، أي
  بطن البالون لا خيطه).
- الحجم **لا يُؤلَّف**: خُمسا ارتفاع الصورة تقريباً، ويصغر ليسع ٨٠٪ من
  عرضها. فكلمةٌ طويلة مثل «دراجة» لا تتجاوز البالون.
- الخطّ Tajawal عريض، أبيض بحدٍّ داكن، فيُقرأ على بالونٍ من أي لون.

**رسمٌ واحد**: `core/text/WordLabel.ts` يرسم الكلمة في المحرّك **وفي
مسرح الاستوديو**، فما تراه المؤلّفة هو ما يراه الطفل.

## ٤. إضاءة حرفٍ في كلمته — مؤثّر `highlight-letter`

```jsonc
{ "type": "highlight-letter", "target": "balloon_1", "to": "ب", "place": "first", "lift": true }
```

| الحقل | يقول |
|---|---|
| `to` | الحرف — **حرفٌ واحد** (تتبعه حركته إن كُتبت: «بَ» حرفٌ واحد) |
| `place` | `first` / `middle` / `last`. بغيابه: كل مواضعه في الكلمة |
| `lift` | يخرج الحرف من الكلمة **بشكله فيها** ويرتفع فوقها |

المدّة الافتراضية ٠٫٨ ث: نصفها يُضاء فيه الحرف، فيرى الصفّ **أيّ** حرفٍ
أضاء، ونصفها الثاني يرتفع فيه.

### ٤.١ الموضع غير الشكل

المحرّك **يحسب** الشكل ولا تكتبه المؤلّفة. الحرف يتّصل بما قبله إن كان ما
قبله يتّصل بما بعده:

| الكلمة | الحرف | الموضع | الشكل المُخرَج |
|---|---|---|---|
| بالون | ب | first | **بـ** |
| كبير | ب | middle | **ـبـ** |
| كلب | ب | last | **ـب** |
| كتاب | ب | last | **ب**: الألف قبلها لا تتّصل بما بعدها |
| أرنب | أ | first | **أ**: الألف لا تتّصل بما بعدها، فلا «أـ» أبداً |

⚠️ لذلك انفصل **الموضع** (ما يسأل عنه الدرس: «تبدأ بـ…») عن **الشكل** (ما
يُرسَم). ولو خُلط الاثنان لخرجت «أـ»، وهو حرفٌ بتطويلٍ لا يُكتب.

### ٤.٢ لماذا تُرسم الكلمة مرّتين ولا تُقَصّ

قصُّ «بالون» إلى «بـ» و«الون» نصّين متجاورين يترك شقّةً بين الحرفين عند
كل خطٍّ لا يطابق قياسُه رسمَه. فتُرسم الكلمة كاملة، ثم كاملةً ثانيةً بلون
التظليل **تحت قناعٍ** لا يكشف إلّا مستطيل الحرف. الوصلات تبقى كما شكّلها
الخطّ.

والمستطيل يُقاس بالواصل الصفريّ (U+200D): «بـ» تُقاس `ب‍`، فيُقاس عرضها
**متّصلةً** كما هي في الكلمة لا منفردة.

عنصرٌ بلا كلمة، أو كلمةٌ بلا الحرف: لا يُضاء شيء، ولا خطأ.

### ٤.٣ اللون — `color`، ولون الكلمة `word.color`

```jsonc
{ "type": "highlight-letter", "target": "balloon_1", "to": "ل", "color": "#2f6fed" }
{ "id": "balloon_1", "alias": "balloon", "word": { "text": "بالون", "color": "#f5c518" } }
```

- `color` على `highlight-letter`: لون الحرف المضاء، `#rrggbb`. بغيابه أخضر الدرس.
- `word.color`: لون الكلمة كلّها. بغيابه أبيض.
- **تلوين كل حرفٍ بلون** ليس حقلاً جديداً: خطوةٌ لكل حرف، ولكلٍّ لونه — معاً
  («مع السابقة في وقت واحد») أو واحداً بعد واحد.
- الصيغة `#rrggbb` وحدها، لا أسماء ألوان: خطأٌ إملائيّ في «red» كان سيُرسم
  أسود على البالون بلا أن يقول أحد شيئاً.

وفي الاستوديو: ثمانية ألوانٍ بنقرة، ولونٌ حرّ من منتقي المتصفّح.

## ٥. `pick-correct` بكلماتٍ وحرفٍ ومسارات

```jsonc
{
  "type": "pick-correct",
  "question": { "text": "اختر الكلمات التي تبدأ بـ«بـ»", "audio": "q_ba" },
  "letter": "ب",
  "place": "first",
  "choices": [
    { "id": "c1", "alias": "balloon", "label": "باب", "correct": true,
      "x": 560, "y": 600, "path": [{ "x": 400, "y": -150 }, { "x": 700, "y": 250 }] },
    { "id": "c2", "alias": "balloon", "label": "كتاب",
      "x": 960, "y": 640, "path": [{ "x": 960, "y": -150 }] },
    { "id": "c3", "alias": "balloon", "label": "بيت", "correct": true,
      "x": 1360, "y": 600, "path": [{ "x": 1550, "y": -150 }, { "x": 1250, "y": 250 }] }
  ],
  "wrongResponse": { "text": "في «كتاب» باءٌ أيضاً… لكنها في آخرها!" }
}
```

| الحقل | يقول |
|---|---|
| `choices[].label` | كلمةٌ على صورة الخيار. الصورة نفسها (بالون) تتكرّر، والكلمة بيانات |
| `choices[].path` | نقاطٌ يطفو عبرها الخيار عند دخوله. **الأولى حيث يظهر**، والمنحنى ينتهي عند `x`/`y` |
| `letter` | الحرف الذي يدور عليه السؤال |
| `place` | أين يُطلب في الكلمة |

### ٥.١ يُرفَع: «جوابٌ صحيح واحد»

`correct` قد يحمله **أي عدد** من الخيارات، ولا يُحلّ النشاط حتى تُختار
**كلّها**، كما صار «ابحث» في [v1.0.31](./Scene-Model-Specification-v1.0.31.md).
والخيار الصحيح الذي اختير لا يُعدّ ثانيةً. وصحيحٌ **بلا صورة** يسقط من
العدّ، وإلّا انتظر النشاط شيئاً لا يُرسم أبداً (درس `isSolvable`).

والقرار القديم («جوابان صحيحان سؤالٌ لم تُكمل المؤلّفة تحديده») كان
صحيحاً للأسئلة التي وُجدت يومها. أمّا «اختر **كل** ما يبدأ بالباء» فسؤالٌ
واحد بجوابين، لا سؤالٌ ناقص.

### ٥.٢ ما يراه الطفل

```
الخيارات   →  تطفو واحداً بعد واحد عبر مساراتها (٢٫٢ ث، بفاصل ٠٫٤٥ ث)
لمسة صحيحة →  نبضة + الباء تُضاء بالأخضر حيث يطلبها الدرس
لمسة خاطئة →  اهتزاز + الباء تُضاء بالبرتقاليّ **حيث تقع فعلاً**
              (في «كتاب»: في آخرها) + ردّ الشخصية
آخر صحيح   →  يُحلّ النشاط، و onSolved كما في كل نوع
```

⚠️ **والخطأ يصير معلومة.** «كتاب» ليست مشتّتاً عشوائياً: فيها باء، لكن في
غير موضعها. والتظليل البرتقاليّ يُريه ذلك بلا كلمة، وهو لبّ الدرس (تمييز
«بـ» من أشكال الباء الأخرى).

⚠️ **ويُلمَس الخيار وهو يطفو.** طفلٌ يفقأ بالوناً في الهواء لم يخطئ شيئاً.

### ٥.٣ الحرف يقترح، ولا يحكم

`letter` **لا يحسب** `correct` في المحرّك. `correct` مؤلَّفٌ كما كان:

- **الاستوديو يقترح**: كتابة الحرف أو الموضع، أو كلمة خيار، تكتب `correct`
  لكل خيارٍ فيه الحرف في موضعه. والمعلّمة تنقض أيّ اقتراحٍ بزرّه، وتعديلُ
  خيارٍ آخر لا يمسّ قرارها.
- **المتحقِّق يحذّر** حين يتخالفان في الاتجاهين.

والسبب أن المتحقِّق يرى الكتابة وحدها: «الشمس» تبدأ كتابةً بالألف
وتُسمَع بالشين. وسؤالٌ عن **الصوت** قرارٌ للمعلّمة لا للمحرّك.

## ٦. ما يفحصه المُتحقِّق

| الحالة | الدرجة |
|---|---|
| `move.path` ليس قائمة نقاطٍ رقمية | خطأ |
| `path` على مؤثّرٍ غير `move` | خطأ |
| `highlight-letter` بلا حرفٍ واحد في `to` | خطأ |
| `place` خارج `first`/`middle`/`last` (في المؤثّر أو النشاط) | خطأ |
| `color` ليس `#rrggbb`، أو على مؤثّرٍ غير `highlight-letter` | خطأ |
| `word.color` ليس `#rrggbb` | خطأ |
| `elements[].word` بلا `text`، أو `y` خارج ٠–١ | خطأ |
| `word` على مجموعة (لا صورة لها) | تحذير |
| `activity.letter` ليس حرفاً واحداً | خطأ |
| `choices[].label` ليس نصّاً، أو `choices[].path` ليس نقاطاً | خطأ |
| خيارٌ `correct` وليس في كلمته الحرفُ في موضعه، أو العكس | تحذير |
| `place` بلا `letter` | تحذير |

والمتحقِّق الخلفيّ (`validators.py`) لم يتغيّر: الحقول الجديدة كلّها
اختيارية ولا تمسّ البنية التي يفحصها.

## ٧. ما لا تضيفه هذه الرقعة عمداً

**حجمٌ مؤلَّف للكلمة.** الحجم قاعدةٌ من الصورة. ورقمٌ يُضبط لكل عنصر هو
ما يجعل ثلاث بالوناتٍ متجاورة تحمل ثلاثة أحجام.

**لونٌ مؤلَّف لتظليل `pick-correct`.** هناك الأخضر والبرتقاليّ **معنيان** لا
زينة: «هنا» و«هنا، لكن ليس حيث سُئل». ولونٌ يختاره كل درس يمحو المعنى.
أمّا `highlight-letter` فعرضٌ تقوده المعلّمة لا حكم، فلونه لها (§٤.٣) —
طلبته المعلّمة صراحةً بعد أن رُفض هنا في المسوّدة الأولى.

**`correct` محسوبٌ في المحرّك** — انظر §٥.٣.

**مسارٌ لغير `move`.** «يدور وهو يطير» تركيبٌ في `parallel` مع `rotate`،
وهو موجود.

**تحرير المسار بسحب نقاطه.** يُعاد رسمه بنقرات. وسحب النقاط تحسينٌ في
الاستوديو لا يحتاج حقلاً، فيُضاف إن طُلب.

## ٨. التوافق

- قصّةٌ أُلّفت قبل هذه الرقعة لا تحمل أيّاً من الحقول الجديدة، فتُقرأ بعدها
  بلا تغيير.
- `pick-correct` بجوابٍ صحيح واحد يُحلّ بأوّل لمسةٍ صحيحة كما كان، لأن
  «كلّها» على جوابٍ واحد هي هو.
- `move` بلا `path` هو الحركة المستقيمة نفسها.
